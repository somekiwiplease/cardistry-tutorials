# Cardistry Tutorials

A list of cardistry moves, each linked to its tutorial, that I put together to learn. Search, filter by type and level, save moves into folders and mark them as learnt; your progress stays in your browser. I'm still a beginner myself, so please don't mind if a few things aren't quite right. Hope it helps you too.

## Credits

This is only a curated list. Every video, move and tutorial belongs to its creator, so please support them on their channels and shops.

The move list started from the r/cardistry Cardistry Hub guide by u/LogicRevolution and the community.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:4490.
